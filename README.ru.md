AstraForge — приложение для Windows, которое на вашем компьютере превращает картинку или текст в игровой 3D-ассет: концепт → геометрия → редактор → риг и анимация → эффекты → экспорт (GLB, OBJ, WebM, PNG, изометрические спрайт-листы, пакеты для Godot). Сервер слушает только `127.0.0.1`. Интерфейс на английском и русском (по умолчанию английский, переключается в приложении).

## Быстрый старт через Claude Code

Нужен [Claude Code](https://claude.com/claude-code).

```powershell
git clone https://github.com/Snodrod/AstraForge C:\AstraForge
cd C:\AstraForge
claude
```

Напишите Claude Code: **«Установи и настрой AstraForge для меня»**. В репозитории есть `CLAUDE.md` с точной процедурой. Claude Code:

1. **Проверит компьютер, ничего не скачивая:**
   `powershell -NoProfile -ExecutionPolicy Bypass -File installer\Install.ps1 -ScanOnly`
   Скрипт покажет видеокарту и видеопамять, свободное место и что уже стоит (Node.js, Blender, ComfyUI, модели Hunyuan3D, SDXL, Godot, Ollama, Pixal3D).
2. **Покажет план и спросит вас**, какие дополнительные компоненты ставить. У каждого свой размер и лицензия:

   | id | Что | Размер |
   |---|---|---|
   | `node`, `npm` | Node.js 22 и сборка интерфейса (обязательно) | ≈ 0,3 ГБ |
   | `blender` | Blender 5.0.1 (обязательно) | ≈ 0,4 ГБ |
   | `comfy` / `comfydeps` | ComfyUI 0.33.2 + Python 3.12 + PyTorch (обязательно) | ≈ 6 ГБ |
   | `hy2`, `u2net` | Hunyuan3D-2 (3D по картинке) и удаление фона (обязательно) | 4,9 ГБ + 0,2 ГБ |
   | `hymv` | Hunyuan3D-2mv: 3D по виду спереди и сзади | 4,9 ГБ |
   | `hy21` | Hunyuan3D-2.1 | 7,4 ГБ |
   | `sdxl` | SDXL: картинка по тексту | 6,9 ГБ |
   | `mvadapter` | MV-Adapter: ракурсы по одной картинке, нужен SDXL | ≈ 3,8 ГБ |
   | `godot` | Godot 4.5.1: проверка пакетов для игры | 77 МБ |
   | `clips` | анимации Quaternius (CC0), нужен Blender | 10 МБ |
   | `ollama`, `llm` | локальный помощник Qwen3 (модель по объёму видеопамяти: qwen3:4b / 8b / 14b) | 2,5–9 ГБ |
   | `vlm` | qwen3-vl:8b: проверка текстур и анимации | 6,1 ГБ |
   | `vfx` | генераторы VFX-текстур | ≈ 0,5 ГБ |
   | `pixal3d`, `pixal3dw`, `pixal3dtest` | Pixal3D: форма по 1–4 видам, RTX 30/40/50 и 10+ ГБ | ≈ 48,5 ГБ |

3. **Запустит установку без вопросов** (`-Yes -Only <ids>`) в фоне: мастер интерактивный, и в окне Claude Code ответить на его вопросы нельзя. Загрузка идёт десятки минут; если она оборвалась, ту же команду повторяют, и она продолжит с места обрыва.
4. **Проверит результат:** повторит `-ScanOnly` и посмотрит `config\paths.json`.
5. **Запустит студию:** `Start.cmd`, затем проверит `http://127.0.0.1:3210/api/health`, где должен быть ответ `"app":"AstraForge"`.
6. **Если что-то не так**, прочитает `installer\install.log`, `data\runtime\server-error.log` и `data\runtime\comfy.log` и переустановит только сломанный компонент: `Install.ps1 -Yes -Only <id>`.

Ключи OpenAI, Anthropic и Tripo не обязательны. Их вводят в студии на вкладке **«Подключения»**, где они шифруются Windows DPAPI. Не вставляйте ключи в чат и не кладите их в файлы репозитория.

## Ручная установка

1. Склонируйте или скачайте репозиторий в короткую папку, например `C:\AstraForge`.
2. Дважды нажмите **Install AstraForge.cmd** и отвечайте на вопросы мастера. Он проверит компьютер, покажет, чего не хватает, с размерами и лицензиями, и скачает всё в эту же папку (`runtime\`, `data\models\`). Прерванная загрузка продолжится при повторном запуске. В конце появится ярлык **AstraForge** на рабочем столе.
3. Запустите студию через **Start.cmd**.

Нет git? Скачайте **AstraForge-Setup-&lt;версия&gt;.exe** в [Releases](https://github.com/Snodrod/AstraForge/releases/latest), запустите и выберите папку: он распакует приложение и запустит тот же мастер. Файл не подписан, поэтому Windows SmartScreen может предупредить: нажмите «Подробнее» → «Выполнить в любом случае».

Найденные пути установщик записывает в `config\paths.json`, а `Start.cmd` берёт их оттуда. Ключи `installer\Install.ps1`:

- `-ScanOnly` — только проверить компьютер;
- `-DryRun` — пройти мастер без загрузок;
- `-Only hy2,u2net` — поставить выбранные компоненты (вопросов о дополнительном нет; перечисляйте в порядке установки). Идентификаторы: `node`, `npm`, `blender`, `comfy`, `comfydeps`, `hy2`, `hymv`, `hy21`, `sdxl`, `u2net`, `godot`, `clips`, `ollama`, `llm`, `vlm`, `mvadapter`, `pixal3d`, `pixal3dw`, `pixal3dtest`, `vfx`;
- `-Yes` — без вопросов (обязательное и то, что мастер предлагает по умолчанию; Pixal3D по умолчанию не ставится).

Журнал: `installer\install.log`.

## Запуск и остановка

1. Дважды нажмите **Start.cmd** (или ярлык **AstraForge** на рабочем столе). Откроется **http://127.0.0.1:3210**. Собственный ComfyUI студии работает на порту 8190; подождите появления статуса Hunyuan3D.
2. Остановка — **Stop.cmd**. Он останавливает процессы этой студии и не трогает другой ваш ComfyUI и Ollama.

Не удаляйте `data`, если хотите сохранить проекты, модели и подключения.

## Возможности

- **Создание.** Загрузите PNG/JPG/WEBP с одним объектом на нейтральном фоне или введите описание (сначала SDXL рисует картинку). rembg удаляет фон на CPU, Hunyuan3D строит геометрию.
- **Ракурсы.** По одному виду спереди (персонаж в T-позе) приложение создаёт виды слева, сзади и справа — через ChatGPT/Codex или локально через MV-Adapter (офлайн, ≈40 с). «Создать 3D по ракурсам» строит модель в Hunyuan3D-2mv по всем видам. См. `docs/forge/views.md` и `docs/forge/views_install.md`.
- **Pixal3D.** Необязательная генерация формы по 1–4 видам (только геометрия, без текстур). См. `docs/forge/pixal3d.md`.
- **Редактор.** Перемещение, вращение, масштаб; цвет, металличность, шероховатость; примитивы; импорт GLB, OBJ и STL (GLB должен содержать встроенные текстуры, внешние ссылки заблокированы).
- **Текстуры.** UV-атлас с сохранением весов, PBR-карты до 4K, рисование по модели, проекция цвета референса. См. `SURFACES-SPRITES-GODOT.md`.
- **Кости.** Шаблоны Humanoid, Quadruped, Mechanical и Custom, правка иерархии, Rest/Pose, скиннинг по расстоянию, кисть весов и библиотека именованных клипов. См. `GODOT-RIGGING.md`.
- **Анимация и эффекты.** Ключевые кадры, готовые клипы (Quaternius CC0, Mixamo), частицы (искры, шлейф двигателя, энергетическое поле) и мастерская VFX-текстур (`docs/vfx-tools.md`).
- **Forge.** Конвейер на Blender: части, предметы в руках, риги, стили движения, kitbash и процедурные научно-фантастические корабли и турели (`docs/forge/`).
- **Экспорт.** GLB, OBJ, WebM, PNG, проекты `.astra.json`, изометрические спрайт-листы (PNG + Godot SpriteFrames) и пакеты для Godot. Профили экспорта: `godot`, `iso8`, `custom`. Всё также сохраняется в `data/exports`.
- **Tripo.** Необязательная вкладка с официальным облачным API Tripo (генерация, обработка сетки, текстуры, авториг, движения, форматы). Нужны ваш API-ключ и кредиты. См. `TRIPO-CAPABILITIES.md`.
- **ИИ-помощник.** По умолчанию локальный Ollama, либо OpenAI / Anthropic с вашим ключом. Помощник возвращает только ограниченный набор проверяемых действий (материал, трансформации, движение, эффекты), которые вы применяете кнопкой. Произвольный код и команды ОС не исполняются.

Горячие клавиши: W — перемещение, E — вращение, R — масштаб, F — вписать в кадр, пробел — воспроизведение, Delete — удалить, Ctrl+D — копия, Ctrl+S — сохранить, Ctrl+Z — отменить, Ctrl+Shift+Z — повторить.

### Дополнительные компоненты

| Компонент | Что даёт | Размер | Требования |
|---|---|---|---|
| **MV-Adapter** (`mvadapter`) | Локально и офлайн строит виды слева, сзади и справа по одной картинке спереди. Узел `huanngzh/ComfyUI-MVAdapter` (с правками AstraForge) попадает в `data\runtime\custom_nodes`, веса — в `data\models\mvadapter` | около 3,8 ГБ (+ SDXL 6,9 ГБ, если его нет) | NVIDIA, лучше 10+ ГБ видеопамяти |
| **qwen3-vl:8b** (`vlm`) | Локальная модель, которая смотрит на картинки: проверка текстур и анимации (`ASTRA_QA_VLM` меняет модель); ставится через Ollama | 6,1 ГБ | Ollama |
| **Pixal3D** (`pixal3d` — движок, `pixal3dw` — веса, `pixal3dtest` — пробный запуск) | Отдельный портативный ComfyUI на порту 8191 (только `127.0.0.1`) с TRELLIS.2 и Pixal3D. Папка по умолчанию `runtime\ComfyUI-Pixal3D`; другую задаёт `ASTRA_PIXAL3D_DIR` (ключ `pixal3dDir` в `config\paths.json`) | загрузка около 42 ГБ, на диске 48,5 ГБ (свободно нужно около 52 ГБ) | NVIDIA RTX 30/40/50, 10+ ГБ видеопамяти (8 ГБ с предупреждением); короткий путь без кириллицы |
| **Генераторы VFX-текстур** (`vfx`) | Material Maker, PixaFlux, KumoWorks, Slate, FlowMap Painter, Pseudo Volume Generator и четыре веб-генератора без интернета (`scripts\vfx\Install-VfxTools.ps1`, каталог `server\vfx-tools-catalog.json`) | загрузка около 330 МБ, на диске около 500 МБ | для DisplacementX нужен Node.js с npm |

Pixal3D ставится по закреплённому рецепту: Python 3.12.10 (подпись проверяется), ComfyUI 0.39.0 и узлы `visualbruno/ComfyUI-Trellis2` на закреплённых коммитах, PyTorch 2.8.0+cu128, закреплённые пакеты PyPI (`installer\pixal3d\requirements-lock.txt`), FlashAttention 2.8.3, `utils3d` 1.7 из GitHub, веса с Hugging Face с проверкой sha256. DINOv3 берётся только из официальной копии timm и преобразуется локально; автоскачивание со стороннего зеркала отключено правкой `ASTRAFORGE PATCH`.

## ИИ и аккаунты

Локальные сообщения остаются на компьютере. При выбранном облачном провайдере (OpenAI или Anthropic) сообщение и описание сцены отправляются его API, для чего нужны ваш ключ и квота. Ключи шифруются Windows DPAPI, хранятся на сервере и не возвращаются браузеру; также поддерживаются `OPENAI_API_KEY` и `ANTHROPIC_API_KEY`. DPAPI-ключи привязаны к вашему пользователю Windows, поэтому при копировании папки другому пользователю ключи не переносятся. ИИ и генерация используют одну видеокарту и работают по очереди.

## Ограничения

Локально нет скульптинга, правки отдельных вершин, обученного нейросетевого авторига, IK и контакта стоп, семантической сегментации и AI-ретопологии; авториг, нейросетевые текстуры и обработка сетки доступны только как облачные операции Tripo. Локальные текстуры процедурные или проекционные. Тяжёлые меши требуют оптимизации; gzip-проекты ограничены 512 МБ распакованного JSON. Это не замена полноценному DCC-редактору. Компоненты следующего этапа разобраны в `RESEARCH-RIGGING-GODOT.md`, архитектура — в `ARCHITECTURE.md`.

## Разработка

Node.js 22.12+; `npm install`, `npm run build`, `npm start` (или `npm run dev`). Тесты: `npm test`. Логи: `data/runtime/server-error.log` и `data/runtime/comfy.log`. Существующий ComfyUI указывается через `ASTRA_COMFY_DIR`. Без ComfyUI редактор работает, но нейросетевая генерация недоступна. Документация модулей Forge — в `docs/forge/`.
