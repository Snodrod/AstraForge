# Обновление native AMD установщика и HIP-колёс

Дата: 2026-11-05.

## Цель

Собрать воспроизводимый установщик ветки `amd-rocm`, который на чистой машине может установить и проверить изолированный фундамент native Windows ROCm и три HIP-расширения на RX 9070 XT. Обновить комплект колёс и лицензии без пересборки неизменившихся бинарных исходников.

Версия результата: `0.3.0-amd.1`. Основной файл: `AstraForge-Setup-0.3.0-amd.1.exe`. Существующий `AstraForge-Setup-0.5.1.exe` не изменяется и не включается в новый пакет.

## Проверенные исходные факты

- После сборки HIP-колёс изменились `scripts/native/patches/lscm-batched-solve.patch`, `installer/mvadapter/patch/astra_views.py` и multiview Python-патчи.
- Бинарные исходники CuMesh, FlexGEMM и O-Voxel после сборки не менялись. Пересборка этих трёх колёс не требуется.
- Существующие колёса собраны для CPython 3.12, PyTorch `2.9.1+rocm7.2.1`, ROCm 7.2.1 и проверены на RX 9070 XT/gfx1201.
- URL ROCm/PyTorch на `repo.radeon.com` доступен. Прежний URL GitHub Release для CuMesh возвращает 404, поэтому внешняя ссылка не используется как источник установки.
- Текущий `Pixal3DNative.ps1` требует локальный кэш `installer/downloads/amd`, но релизный пакет этот кэш не содержит. Это блокирует установку на чистой машине.
- Текущий release script может упаковать старый корневой EXE и каталог `verification/`.

## Поведение установщика

1. Проверить безопасный абсолютный путь изолированного native runtime. NVIDIA, WSL и системный Python не изменяются.
2. Перед установкой проверить каждый локальный файл по размеру и SHA-256. Отсутствующий или повреждённый официальный пакет скачивается заново; несовпадение после загрузки является фатальной ошибкой.
3. Проверить встроенные HIP-колёса по тем же правилам. Скачивание их из непроверенных внешних источников не выполняется.
4. Установить официальные ROCm/PyTorch пакеты и три HIP-колеса в `runtime/ComfyUI-Pixal3D-AMD-Native/python_embeded` с `--no-deps`, чтобы не подменять закреплённый ROCm-стек.
5. Запустить существующий base probe и `probe_trellis2_extensions.py`. Отчёты содержат фактические версии, GPU, проверки и пути к установленным модулям.
6. Записывать отдельные marker-файлы только после успешных проверок. `native-ready.json` и production-флаги режимов генерации автоматически не изменяются.

`ProbeOnly` не скачивает и не устанавливает файлы. `DryRun` не изменяет runtime. Повторный запуск использует корректный кэш и не повторяет загрузку. Любая ошибка оставляет понятное сообщение с именем файла или проверки; драйверы, сеть, WSL и перезагрузка не затрагиваются.

Полные исходники ComfyUI/TRELLIS.2, веса моделей и production-допуск генерации остаются отдельными этапами. Успешная установка колёс не объявляется готовностью полного 3D-пайплайна.

## Сборка релиза

- Обновить версию пакета до `0.3.0-amd.1` согласованно в package-манифестах.
- Исключить из payload корневые `AstraForge-Setup-*.exe`, `verification/`, runtime, модели, кэши и пользовательские настройки.
- Включить актуальные исходники, dist, production node_modules, три HIP-колеса, манифесты, патчи LSCM/MV-Adapter/multiview и уведомления о лицензиях.
- Сохранить Setup, SHA-256 и отдельный ZIP с тремя HIP-колёсами, `wheels.json` и лицензиями в `delivery/astraforge-amd-native-2026-11-05` внутри рабочей области.

## Проверки

### Без GPU

- Unit-тесты манифеста: все обязательные файлы, URL, размеры и SHA-256 присутствуют; CUDA-пакеты запрещены.
- Unit-тесты загрузчика: корректный кэш не скачивается повторно; отсутствующий и повреждённый файл обрабатывается; ошибка хеша блокирует установку.
- Проверить `ProbeOnly`, `DryRun`, безопасность путей и отсутствие вызовов драйверов, WSL и перезагрузки.
- Прогнать существующие Node/Python-тесты и сборку интерфейса.
- Распаковать новый Setup во временную папку и проверить наличие патчей, колёс, лицензий и отсутствие старого Setup и `verification/`.
- Сверить размеры и SHA-256 упакованных HIP-колёс с исходными файлами.

### RX 9070 XT

- Проверить фактические SHA-256 трёх исходных HIP-колёс перед упаковкой.
- Выполнить base probe и extension probe последовательно в одном native runtime, без параллельных GPU-задач.
- Подтвердить `nativeReady: true` для базового фундамента и `shapeReady: true` для расширений, изучив каждую обязательную проверку, а не только код выхода.
- Не запускать полную генерацию и не менять `native-ready.json`: этот этап проверяет установку и расширения, а не новый режим генерации.

## Критерии приёмки

- Новый Setup не зависит от заранее существующего `installer/downloads/amd`: официальные файлы скачиваются и проверяются, HIP-колёса уже находятся внутри пакета.
- Все девять пакетов имеют проверенные хеши; три HIP-колеса побайтно совпадают с проверенными экземплярами.
- Base и extension probes успешны на RX 9070 XT.
- Старый установщик, превью, runtime и пользовательские данные не попали в релиз.
- Тесты и распаковочная проверка завершены, результаты и ограничения записаны в документацию.
